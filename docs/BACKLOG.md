# Бэклог

Идеи и улучшения после релиза 0.1. Текущая работа — в [TODO.md](TODO.md).

## Подбор
- Группы взаимозаменяемых товаров (белый / золотой / тёмный ром, виды сахара и т.п.): подставлять замену и показывать «можно заменить на…».
- Режим «отмечать и необязательные ингредиенты» (соки, цитрусы, декор) для строгого подбора.
- Настраиваемый порог недостающих ингредиентов в `/settings` (сейчас 0, 1, 2 — отдельными разделами).
- Fallback на другую локаль для коктейлей, которых нет в языке пользователя (сейчас не показываем).
- Предвычисленные таблицы/материализованное представление, если данных станет заметно больше (сейчас ~668 коктейлей, не нужно).

## Пользовательский опыт
- Избранные коктейли и «уже готовил».
- Случайный коктейль из доступных («удиви меня»).
- Фильтры в выдаче по тегам коктейля (крепкие, кислые, на соке…).
- Список покупок из выбранных коктейлей.
- Отметка гаджетов, которые есть у пользователя.
- Пересчёт количеств на число порций.
- Фото коктейлей, если появятся в данных.

## Данные
- Механизм обновления справочника (новые коктейли) без потери ручной разметки `is_essential`.
- Ручная проверка и правка `is_essential` по результатам обратной связи.

## Инфраструктура
- Админ-команда со статистикой (по образцу `/admin` в poi-bot).
- Метрики Micrometer: популярные ингредиенты, доля пустой выдачи.
- Команда `/deleteme`: выгрузка и удаление данных пользователя.
